# 03 — UI (`ui`)

**Archivos:** `app/components/**`, `app/lib/site.ts`

## Estructura

| Carpeta | Componentes |
|---------|-------------|
| `ui/` | `Section` (id + eyebrow + h2 + intro, `tinted` alterna fondo), `ButtonLink` (primary/secondary, external, download), `ExternalLink`, `icons.tsx` |
| `layout/` | `SiteHeader` (sticky, logo "MS", nav por anclas, toggle, skip link), `ThemeToggle` (client), `SiteFooter` (build info + link al CI) |
| `sections/` | `Hero`, `Projects` + `ProjectCard`, `Stack`, `About`, `Contact` + `ContactForm` (client) |

## Contratos

- **ids de sección** = `NAV_ITEMS` (`SectionId`); `Section` exige un `SectionId`. Hero usa `#top`, main `#main`.
- **ids de proyecto** = `slug`; cada `ProjectCard` es `<article id={slug}>` con `aria-labelledby` al título.
- Imágenes: `next/image`. Screenshots con `fill` + `sizes` + `aspect-[16/10]`; avatar 160×160; logos SVG con `unoptimized`.
- Links externos: `ExternalLink`, `ButtonLink external` o `target="_blank" rel="noopener noreferrer"` (tests lo validan).

## Patrones

- Contenedor estándar `mx-auto max-w-6xl px-6`; secciones `py-20 sm:py-24` con `border-t`.
- Proyectos: grilla 1 / 2 / 3 columnas; chips de tecnología `bg-accent-soft text-accent`.
- Stack: grupos en 1 / 2 / 3 columnas, dos ítems por fila con tile de logo.
- Mobile: nav visible completa (4 links + toggle); el nombre del logo pasa a `sr-only` (conserva nombre accesible).

## Accesibilidad (verificada por axe en CI)

- Un solo h1; cada sección `aria-labelledby` su h2; skip link a `#main`; foco visible.
- Formularios con `label htmlFor`, `aria-invalid`, `aria-describedby`, `role="alert"`/`"status"`.
- Imágenes con `alt` descriptivo; logos del stack `alt=""` (el nombre está al lado como texto).

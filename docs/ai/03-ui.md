# 03 — UI (`ui`)

**Archivos:** `app/components/**`, `app/lib/{site,motion,active-section,companion,tags,deploy}.ts`

> Para el compañero, la nav con sección activa, las etiquetas detectadas, la física o el contacto, usar la
> skill **`companion`** (`.claude/skills/companion/SKILL.md`).

## Estructura

| Carpeta | Componentes |
|---------|-------------|
| `companion/` | `Companion` (aside sticky en ≥ lg / botón "Ask Matias" + `<dialog>` en móvil), `CompanionPanel` (Guide / Ask / Deploy, avatar, "Next ↓"), `Typewriter` |
| `ship/` | `DeployWidget` (pipeline real), `StackPlayground` (matter-js) |
| `ui/` | `Section` (badge numerado + título + tagline manuscrita + intro; marca `data-companion-section`), `ButtonLink` (pill blanca / contorno), `TechTag` (logo + nombre), `icons.tsx` |
| `layout/` | `IntroScreen`, `ScrollChoreography` (revelados + Lenis), `SiteHeader` (client: monograma, pills 01–05 con la activa iluminada, CV.PDF, "Let's talk"; en móvil "Jump to"), `SiteFooter` |
| `sections/` | `Hero`, `Hub`, `Experience`, `Projects`, `Stack`, `Certifications`, `About`, `Contact` (+ `ContactForm`, `CopyButton`) |

## Layout

`page.tsx`: grilla de dos columnas desde `lg`, con el contenido (`min-w-0`) a la izquierda y el compañero
sticky (22–25rem) a la derecha. Todo el texto del compañero (narración, respuestas, script del deploy) se
arma en el servidor y viaja como props.

## Recorrido

| Sección | Qué es |
|---------|--------|
| Hero `#top` | estado + empresa más reciente, "hello, I'm" manuscrito, nombre con subrayado que se dibuja, rol + intro, CTAs, highlights |
| Hub | tarjetas GitHub (repos de los proyectos), LinkedIn (estado y foco), CV |
| 01 Experience | tarjeta por empresa: ubicación, Current/Completed (del período), roles, logros, **etiquetas detectadas** con logos |
| 02 Projects | Shipped / In development, captura, descripción, tech con logos, Live site / Code |
| 03 Stack | chips con logo por grupo + caja con física |
| 04 Certifications | tarjetas con monograma del emisor, nombre, fecha |
| 05 About | foto, bio, facts como "sheets", educación |
| Contact `#contact` | "so… Let's talk.": Gmail / Outlook / app de correo / Copy address, canales, formulario, "Back to top" |

## Contratos

- ids de la nav = `NAV_ITEMS` (experience, projects, stack, certifications, about); `top` y `contact` fuera de la nav.
- La nav principal se llama "Sections" (≥ lg) y la compacta "Jump to". La pill activa lleva `aria-current="location"`.
- Test ids: `companion`, `companion-answer`, `deploy`, `stack-playground`, `intro`, `build-info`.
- Links externos: `target="_blank" rel="noopener noreferrer"` (+ `sr-only` "opens in a new tab" donde el texto no lo dice).

## Accesibilidad (axe con y sin reduced motion, después de recorrer la página)

- Un solo h1.
- Pestañas ARIA completas.
- Narración tipeada `aria-hidden` + live region con el texto completo.
- `<dialog>` nativo en móvil.
- Badges numerados y subrayado `aria-hidden`.
- Botones llenos en `accent-strong`.

## Rendimiento

Sin video ni 3D. matter-js y el deploy se cargan solo cuando se usan. GSAP y Lenis son chunks dinámicos.

# 03 — UI (`ui`)

**Archivos:** `app/components/**`, `app/lib/site.ts`

## Estructura

| Carpeta | Componentes |
|---------|-------------|
| `ui/` | `Section` (id + eyebrow + h2 + intro, `tinted` alterna fondo), `ButtonLink` (primary/secondary, external, download), `ExternalLink`, `icons.tsx` |
| `layout/` | `IntroScreen` (pantalla de bienvenida), `SiteHeader` (sticky, logo "MS", nav por anclas, toggle, skip link), `ThemeToggle` (client), `SiteFooter` (build info + link al CI) |
| `sections/` | `Hero`, `Projects` + `ProjectCard`, `Experience`, `Stack` (tiles con logo o iniciales), `About` (bio, facts, educación, certificaciones), `Contact` (email, teléfono, LinkedIn, GitHub + `ContactForm` client) |

## Contratos

- **ids de sección** = `NAV_ITEMS` (`SectionId`); `Section` exige un `SectionId`. Hero usa `#top`, main `#main`.
- **ids de proyecto** = `slug`; cada `ProjectCard` es `<article id={slug}>` con `aria-labelledby` al título.
- Imágenes: `next/image`. Screenshots con `fill` + `sizes` + `aspect-[16/10]`; avatar 160×160; logos SVG con `unoptimized`.
- Links externos: `ExternalLink`, `ButtonLink external` o `target="_blank" rel="noopener noreferrer"` (tests lo validan).

## Patrones

- Contenedor estándar `mx-auto max-w-6xl px-6`; secciones `py-20 sm:py-24` con `border-t`.
- Proyectos: grilla 1 / 2 / 3 columnas; chips de tecnología `bg-accent-soft text-accent`.
- Stack: grupos en 1 / 2 / 3 columnas; cada ítem en su fila con tile (logo o iniciales) y nombre. Sin niveles de dominio (decisión del autor).
- Mobile: la nav se desplaza horizontalmente si no entra; ítems con `hideOnNarrow` (Stack) se ocultan bajo 400 px para que Contact siempre se vea. El nombre del logo pasa a `sr-only` (conserva nombre accesible).
- Fondos alternados: Projects, Stack y Contact `tinted`; Experience y About lisos.

## IntroScreen (pantalla de bienvenida)

- Nombre letra por letra → línea de acento → "Welcome to my portfolio" → el panel se desliza hacia arriba (~2.6 s).
- **Solo CSS** (clases `.intro*` y keyframes en `globals.css`), Server Component, sin JS de animación.
- Una vez por sesión: `INTRO_INIT_SCRIPT` (`lib/intro.ts`, inline en `<head>`) marca `html[data-intro="seen"]` y el CSS la oculta antes del primer paint.
- Se omite con `prefers-reduced-motion`; `pointer-events: none` (nunca bloquea clics); `aria-hidden` (la h1 real está en el Hero).
- Tests: `IntroScreen.test.tsx`, `intro.test.ts`, `e2e/intro.spec.ts`.

## Accesibilidad (verificada por axe en CI)

- Un solo h1; cada sección `aria-labelledby` su h2; skip link a `#main`; foco visible.
- Formularios con `label htmlFor`, `aria-invalid`, `aria-describedby`, `role="alert"`/`"status"`.
- Imágenes con `alt` descriptivo; logos del stack `alt=""` (el nombre está al lado como texto).
